# PostPredict

PostPredict is a SwiftUI app I created to predict how a social media post might perform based on different inputs.

## What the app does
The app allows users to create a simple profile by entering things like follower count, content niche, posting frequency, and platform. Then, users can input a caption and select post details such as platform, post type, and posting time. Based on this information, the app generates an engagement score, estimated likes and comments, and a few strategy suggestions.

## Data and functionality
This app does not use an external API. Instead, it uses a custom-built prediction system that runs locally in the app. The prediction is based on factors like platform, post type, timing, caption length, and follower count. The goal was to simulate how different choices might impact engagement.

## How I used AI
I used ChatGPT to help generate code examples, fix issues, and improve the overall structure of the app. I also used it to better understand SwiftUI concepts and refine the design. I reviewed and modified the code to make sure everything worked correctly and fit my project.
